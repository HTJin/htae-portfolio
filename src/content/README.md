# Portfolio content

Edit these files to update the site. Layout, animations, and styling stay in React components.

| File | What to edit |
| --- | --- |
| `src/content/index.js` | Name, tagline, email, links, page title/description |
| `src/content/skills.js` | Skills groups |
| `src/content/experience.js` | Work history (add `drawer: [...]` for expandable entries) |
| `src/content/education.js` | Degree and certifications |
| `src/lib/projects.js` | Project showcase cards |
| `public/resume.pdf` | Downloadable resume |

After content changes, run `npm run dev` locally or deploy as usual.
